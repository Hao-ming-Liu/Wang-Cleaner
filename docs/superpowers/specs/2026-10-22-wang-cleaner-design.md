# 王清理：无 root 安卓广告辅助跳过设计

## 目标与约束
用户要可安装的安卓软件，自动处理其他 APP 开屏广告和误触跳转，按 APP 查看次数，尽量开机恢复和抵抗后台清理，低功耗，允许开发者模式但不依赖 root。本项目为从零独立实现，参考 GKD 的事件驱动、规则匹配、按应用管理思路，不冒充 GKD，不复制其代码或订阅，不承诺兼容完整 GKD 选择器。

## 方案选择
采用原生 Android AccessibilityService + 本地规则 + SQLite。本地 VPN 只能过滤部分域名，无法可靠判断开屏按钮或跳转；系统级启动拦截需要普通应用没有的权限，因此不作为无 root 基线。首版使用 Java 与平台视图以降低依赖、安装包和运行开销，minSdk 26，targetSdk 根据本机已安装 SDK 确定且不少于 35。

## 权限与真实边界
- 必选：用户在系统中开启无障碍服务；能读取可访问的界面节点、执行明确的按钮点击与返回。必须显示用途说明和停用入口。不读取密码，不存储屏幕正文。
- 可选：通知权限用于状态/开机提醒；电池优化白名单、厂商自启动和后台无限制由用户在系统设置开启。
- 自动接收 BOOT_COMPLETED / MY_PACKAGE_REPLACED 后检查状态与提醒；无障碍的重新绑定由系统决定。无法自行授予无障碍权限，无法保证被强行停止后恢复。
- 不申请网络、悬浮窗、存储全盘、root、传感器、定位、联系人权限；使用系统文档选择器导入规则和导出统计。
- 不能保证阻止广告网络加载、不可访问 Canvas/视频节点、摇一摇传感器行为、所有跨 APP 启动。返回操作发生在跳转之后，可能有页面闪现。

## 功能与数据
1. 首页：真实连接状态、保护总开关、累计/今日/分类次数、设置引导。
2. 应用：列出可启动 APP，每个 APP 独立开启开屏辅助与跳转提示处理，默认未选择应用不开启。允许手工添加包名。
3. 开屏辅助：仅进入选中 APP 后 12 秒内，匹配明确“跳过广告”/“跳过 5s”等小型可点击节点，裸“跳过”须位于顶部或有广告标识；拒绝大面积父节点点击。每次前台会话最多一次成功动作。
4. 跳转防护：匹配同一界面中的明确跨应用打开提示和“取消/留在当前应用/暂不”等按钮。可选来源包名→目标包名返回规则，仅在来源开屏窗口内且看见明确广告证据后的 3 秒内生效；一次返回，不循环；默认不启用，精确设置，不猜测正常支付/登录跳转。
5. 规则：本地 JSON 格式、显式 package/activity/resource-id/text/context 条件；导入有体积/数量/字段验证，失败不覆盖已有规则。不下载任意订阅、不运行脚本。内置规则只针对用户选择的 APP。
6. SQLite：每次 Android 接受动作后记录来源包、类别、规则、时间；显示为“成功发出操作”，不是视觉确认广告消失。失败不计数，短时间重复去重。按 APP/今日/累计聚合，最近记录限 300 条，累计按日持久化。CSV 导出防公式注入，清空需明确确认。

## 低功耗策略
只接收窗口/内容事件，合并事件、最短扫描间隔 250ms；无屏幕/锁屏不扫描；开屏窗口外不扫描开屏；最多遍历 180 节点/次；不截图、不 OCR、不网络、不持有 WakeLock、不定时拉起。服务不依赖 Activity 存活。默认不增加无实际工作目的的前台保活服务。

## 验证与交付
可导入 Android Studio 的完整工程、中文说明、本地构建脚本、APK（本机构建成功时）、示例规则、自有测试页面/测试 APK。纯 Java 测试覆盖规则误触边界、时间窗口、去重、跳转证据与限频；Android 编译验证 API/Manifest，若可用模拟器则完成安装、启用、自动点击、统计持久化和重启测试。未连接真机时不声称兼容所有第三方 APP 或实测电量。

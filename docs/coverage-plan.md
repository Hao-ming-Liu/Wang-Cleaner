# 全应用广告辅助扩展

用户范围：所有 APP 的开屏广告、广告弹窗、误触跳转。目标是扩大可识别覆盖，不承诺所有广告，保持无 root、事件驱动和有限扫描。

1. 全局 allApps 开关默认关闭（升级保留旧配置）；每个 splash/prompt/popup 布尔覆盖优先于全局默认。加入 popup 统计和规则校验。应用列表可单独关闭；系统授权界面、桌面、输入法等从服务排除。
2. popup 独立于开屏时间窗。内置只接受明确关闭广告文字；普通关闭或无文字按钮必须通过 package + activity + context + text/viewId 的精确本地规则。不能将通用关闭按钮当广告。
3. 有限两分钟内存诊断：按包名记录事件/扫描/候选/点击成功失败和拒绝阶段，不记录页面文字、ID、截图；最多32个包。可在设置开始、查看、复制。
4. 核心与设备测试覆盖全局开启、单应用关闭覆盖、弹窗关闭和普通关闭不动、统计分类、诊断边界；构建1.03并保留真机未验证说明。

跳转保持明确来源→目标、来源启动窗口和近期广告证据约束，只有事后返回。GKD完整格式不在本次兼容范围；不假造第三方 APP 专用规则。

进度：实现与模拟器验证完成，详见 VERIFICATION.md。对照 GKD 源码补充有限文字查询、桌面会话跟踪、弹窗窗口尺寸修正及最多一次的冷却重验。已有1.02真实应用失败原因尚未确认，统计0不能区分未匹配与操作失败，需用新版诊断在目标手机复测。
